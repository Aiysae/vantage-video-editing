# 声音与混音规范

## 音轨结构

| 轨 | 内容 | 来源 |
|---|---|---|
| VO | 原口播（剪辑后） | 源视频，保留原声，不重录 |
| SFX | 动作音效 | `sound/library/`（有授权的音效库）；按 sfx-map 自动排布后人工微调 |
| BGM | 背景音乐（**参考片风格必需**） | 用户指定或有授权曲库；节拍型电子 / lo-fi hip-hop，低频鼓点清楚、中频有拨弦或键盘，无人声 |

三轨分别导出（`vo.wav`、`sfx.wav`、`bgm.wav`）再混音，便于剪映里继续调整。

## 电平基准（初始值，参考片音轨分析后校准）

| 项 | 目标 |
|---|---|
| 成片整体响度 | **-14 LUFS**（短视频平台常用；抖音/视频号会再做响度归一） |
| 真峰值 | ≤ -1.0 dBTP |
| 人声 | 主导，短时响度约 -16 ～ -14 LUFS；必要时轻压缩（2:1，减益 ≤ 4dB） |
| 音效 | 相对人声 -9 ～ -26 dB（按 sfx-map 的 gain）；ui_beep 约 -9 dB，impact 最响但最少用，type/flow 最弱 |
| 参考片实测 | 整体 -17.7 LUFS（未按平台标准做响度），人声段约 -17.8 LUFS，底乐+音效约 -32 LUFS |
| BGM | **比人声低约 15–16 dB**（参考片实测 15.5 dB），全片连续，真人段也不撤；停顿 > 0.8s 时可回升 3–4 dB |
| 静音段 | 不加 BGM 填满；转场留白可以只有一个 whoosh |

## 排布规则

0. **先铺 BGM，再点音效。** 参考片的“声音感”主要来自连续底乐；离散音效稀疏（建议每分钟 8–20 个），不要每个动画都响。
1. 音效对齐**视觉峰值帧**：出现的第一帧、落定帧、打勾完成帧、印章接触帧。whoosh 提前 0.1s 左右，让声音“带出”画面。
2. 连续动作（计数、柱长、流点）用一个连续音效覆盖整个 progress，不要每帧一个 tick。
3. 每秒 ≤ 3 个音效，间隔 ≥ 0.12s；同一类别连续触发时轮换 2–4 个样本，避免机械重复。
4. 人声重音词 ±80ms 内不放 impact/whoosh。
5. 立体声：HUD 在左/右上时，对应 pop 轻微偏向该侧（±15%）；全屏图形居中。
6. 程序合成音只能当占位（报告注明）；正式交付用素材库音效。

## 音效库（已就绪）

`sound/library/<类别>/`：132 个 48kHz/24bit 文件，16 类（click、pop、tick、ding、error、type、swish_soft、glitch、scan、riser、impact、cut、snap、whoosh、ui_beep、flow）。来源为 Kenney CC0 音效包加程序合成音，逐条许可记录在 `sound/library/LICENSES.md`。新增素材必须在该文件登记来源和许可，没有记录的文件不进成片。

## BGM 参考曲目

项目提供音乐文件，`sound/bgm/` 保留两首参考曲目的选曲信息，规则在 `rotation.json`，许可在 `LICENSES.md`（Mixkit 免费商用、无需署名）。

| 曲目 | 感觉 | 用于 |
|---|---|---|
| Hazy After Hours（2:07） | 低调、夜色、高级克制 | 深度观点、行业分析、AI 原理/方法论、冷静论证；≤2 分钟短片 |
| Deep Urban（4:49） | 沉稳商务 House | 商业案例、趋势机会、增长与成果、工作流/实操演示；>2 分钟长片 |

选曲：按全片主基调选一首（不在片中途换曲）。两首都合适时，换成和上一条视频不同的那首（`rotation.json` 的 `last_used`）。用户指定曲目时以用户为准。

铺设：`scripts/bgm_layout.py <曲目> vo.wav <时长> bgm.wav --mark-used` —— 自动按人声定标（-15.5 dB）、不够长时 2 秒交叉淡化循环、头尾淡入淡出、人声停顿时回升 3 dB。混音顺序：人声 + sfx.wav + bgm.wav → `scripts/master.sh`。

## 检查

渲染后先 `scripts/master.sh 渲染.mp4 成片.mp4` 做两遍响度标准化（HyperFrames 直出约 -22 LUFS，未标准化不得交付），再用 `scripts/loudness.sh 成片.mp4` 复核整体响度、真峰值、LRA。另外：
- 原速完整听一遍：人声是否始终清楚，有无音效盖住字词。
- 用耳机听一遍：左右声像是否突兀。
- 手机外放听一遍：impact 低频是否只剩“噗”声（不行就加中频成分）。
四项分别记录，不互相替代。
