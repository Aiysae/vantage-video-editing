# 参考片音轨分析（校准 sfx-map 用）

## 2026-10-03 分析结论（已写入 sfx-map.json）

文件：`视频剪辑/8980b724fbccc50c84ab62a65ebcd91d.mp4`；中间产物在 `视频剪辑/ref-audio/`（分离音轨、频谱图、候选点）。

1. **底乐是主体**：全片连续的节拍型底乐，低频鼓点明显，中频有拨弦/键盘音型；比人声低约 15.5 dB，各类画面段一致。节拍速度自动估计不稳定（可能分段换曲），不作定论。
2. **标志提示音**：“短低音 ≈1.17kHz → 持续高音 ≈2.35kHz”，17 次，≈ -9 dB（相对人声），出现在打叉、标记、状态确认、计数结果等节点。
3. **转场不配 whoosh**：36 个真人↔图形转场附近的能量峰值和随机时间点无差异。
4. **巨字不配冲击音**：21.9万等人物后巨字段未检出明显冲击。
5. **稀疏高潮音**：剪辑删除段（约 414–420s）有 glitch、提示音、气泡音和收尾的宽频冲击；脑内化段结尾（≈118s）有低频 boom 加提示音。
6. 离散音效与 132 个画面事件的对齐率只比随机略高（±0.3s 内 87 vs 随机 77）——说明多数画面动作**没有**单独配音效，节奏感靠底乐。

局限：只做了音轨分离和频谱/能量分析，**没有人耳听辨**；被底乐盖住的轻微 UI 音可能漏检。下次可由用户抽听 `ref-audio/` 中的片段复核。

## 复跑流程

## 前置

用户把参考视频复制到可访问位置（例如 `./assets/reference.mp4`，替代当前指向微信目录的软链接）。

## 步骤

1. **抽音轨**：`ffmpeg -i reference.mp4 -vn -ac 2 -ar 48000 ref.wav`
2. **人声分离**：`scripts/analyze_audio.py ref.wav --separate`（使用 Demucs htdemucs 两轨模式；首次需安装 `demucs`，约 2GB 模型，安装前征得用户同意）。得到 `vocals.wav` 与 `no_vocals.wav`（= 音效＋BGM）。
3. **起音检测**：`analyze_audio.py no_vocals.wav --onsets` 输出 `onsets.csv`（时间、强度、频谱质心、时长估计）。
4. **与视觉事件对齐**：脚本把每个起音点匹配到 `复刻事件清单.json` 中最近的事件（±0.5s），输出 `sfx-observed.csv`。
5. **人工听辨**：逐条听 no_vocals 片段（脚本可切出 0.8s 小样到 `clips/`），标注类别（whoosh/pop/click/type/tick/ding/impact/riser…）。不能靠频谱猜测代替听辨。
6. **BGM**：在长停顿处测 BGM 相对电平；判断是否有、风格、是否随章节变化。
7. **统计并写回**：每类音效的数量、平均 gain（相对人声）、相对视觉峰值的平均 offset、每分钟密度 → 更新 `sfx-map.json` 并将 `calibrated` 设为 true，附 `sfx-observed.csv` 路径。

只提取**规律**（什么动作配什么类别、多响、提前多少）；不从参考片截取任何音频用于成片。
