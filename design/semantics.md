# 语义动效方法论：从“这句话在说什么”推出“画面里发生什么”

用户 2026-10-03 确认的底层原则。适用于任何口播视频，不针对某一条片子。

> 动效不是给字加动画，而是把这句话里**被作用的那个东西**和**它身上发生的变化**演出来。字只是标签，主角是对象。

反例（2026-10-03 用户指出）：“用 AI 把客服砍一半”做成“剪刀剪断一根横条”——横条不是口播里的东西。上下文里被砍的是**人**，所以画面应是“一排客服人员，一半被清掉”。

---

## 1. 五问推导（每个候选句都走一遍，写进 storyboard 的 `semantic` 字段）

| 问 | 要回答的 | 写入字段 | 例：“朋友圈有人说用 AI 把客服砍了一半” |
|---|---|---|---|
| ① 指代 | 这句话里的东西**在上下文里具体是什么**？代词、省略、比喻都要还原。 | `referent` | 被砍的 = 客服**人员**（不是成本、不是条形图） |
| ② 动作 | 对它做了什么 / 它怎么变了？用一个可演出来的动词。 | `action` | 砍掉、清掉 |
| ③ 结果 | 变化后是什么状态？有数量就给数量。 | `result` | 只剩一半人 |
| ④ 情绪 | 说话人希望观众此刻是什么感受？0–3 级。 | `intensity` | 2：震惊、羡慕 |
| ⑤ 视角 | 这句是谁的视角？事实 / 他人说的 / 内心独白 / 引语 / 假设。 | `voice` | 他人说的（朋友圈转述）→ 放在手机/朋友圈语境里 |

**推导出画面**：referent 做成可见对象 → action 做成对象身上的动作 → result 做成动作结束后的静止状态（阅读停留 ≥1.2s）→ 文字只作标签或强化。

## 2. 指代还原规则（最容易错的一步）

- **往前读 2–3 句**再定 referent。“砍一半”“接过去”“落了地”“关门”都要看前文主语和宾语。
- 比喻要还原到**比喻本体**：
  - “悬着的感觉一下就落了地”：对象是“悬着的心”，可以演成悬挂的重物，绳子断了，重物砸地。
  - “他直接就关门了”：对象是“对 AI 的接受度”，可以演成一扇门“啪”地关上，门缝里的光被切断。
  - “被割了”：对象是老板的钱或信任，演成刀劈开一个字，留下一道裂缝。
- 数量必须来自口播：“一半”就是一半人，“三个人的活”就是三个人汇成一个。没说数量就不要编数字，用比例或示意表达。
- 代词“他/它/这个”一律解析到具体对象。解析不出来，就退回文字强调，不要乱配画面。

## 3. 动作 → 视觉动词库（举一反三的抓手）

先把口播动词归到下面的**视觉动词**，再选组件。同一个视觉动词可以用在不同对象上。

| 视觉动词 | 口播里的说法（示例） | 画面原型 | 组件 |
|---|---|---|---|
| 削减 / 清除 | 砍一半、裁员、去掉、省掉 | 一组对象中的一部分被标红后清走，剩余的重新排好 | `KX.crowd` |
| 合并 / 替代 | 一个人干三个人的活、接过去、取代 | 多个对象汇成一个（或被另一个吸收） | `KX.merge` |
| 增长 / 加速 | 往上走、再快一点、翻倍 | 对象拉伸、带速度线、柱子长高、计数上涨 | `KX.speed`、`MU.A.vBars` |
| 停滞 / 原地 | 没涨、还是这样、没动 | 平线、原地打转、指针不动；印章“还是这样” | `MU.path`、`MU.stamp` |
| 流失 / 花掉 | 钱花出去了、成本一分没少 | 钱币从钱包或账户里一枚枚落下、余额下降 | `KX.coins` |
| 断裂 / 失去 | 续费没了、合作断了、信任没了 | 合同被撕开、链条断开、横条被抽空 | `KX.tear` |
| 劈开 / 受伤 | 被割了、被坑了、亏了 | 大字被刀劈开，红色裂缝，画面震动 | `KX.slash` |
| 关闭 / 拒绝 | 关门、拒绝、不再考虑 | 门“啪”地关上，光被切断 | `KX.door` |
| 落定 / 安心 | 踏实、落了地、稳住了 | 悬着的重物落下砸地，扬起灰尘，随后静止 | `KX.drop` |
| 不安 / 焦虑 | 焦虑、慌、睡不着 | 字发抖、色差错位、心电图式跳动 | `KX.jitter` |
| 对比 / 压倒 | 比……还大、远超、不如 | 大的那个砸下来，把小的挤开，中间出现大于号 | `KX.weigh` |
| 传播 / 扩散 | 到处说、口碑、刷到 | 一个气泡复制成很多个向外扩散 | `KX.spread` |
| 寻找 / 定位 | 找问题、卡在哪、找准 | 放大镜在流程上扫过，停在红色节点上 | `KX.scan` |
| 命中 / 落点 | 有地方落、对准、见效 | 飞镖射中靶心并发出一圈光 | `KX.dart` |
| 缩短 / 提速（时间） | 从两小时降到十分钟 | 时钟指针倒转，计数从大往小滚动 | `KX.clock` |
| 引述 / 反问 | “上次那个不就没用吗” | 宋体引语逐词砸下，关键词标红并画下划线 | `KX.quote` |
| 独白 / 旁白 | 他心里想、老板的结论是 | 等宽字体打字机效果 | `KX.typer` |

新视频遇到表里没有的动词：先找最近的视觉动词，再按“对象＋动作＋结果”做一个新原型，补进本表，并在 `components/kx.js` 里加组件。

## 4. 表达等级与节奏预算

| 等级 | 用法 | 预算（每分钟） |
|---|---|---|
| L0 只有字幕 | 过渡句、口头禅 | — |
| L1 标签 / 胶囊 | 补充信息 | 不限，但同屏 ≤3 个 |
| L2 关系图形 | 流程、对比、数据 | 是主体（约占 50% 时长） |
| L3 动作隐喻 | 第 3 节的视觉动词，作用在**具体对象**上 | 3–5 次 |
| L4 冲击 | 全屏压暗 + 巨字或巨物 + 震动 + 冲击音效 | 全片 6–8 次，只给 intensity=3 的句子；两次之间至少隔 20 秒 |

- **人物后大字（behind giant）**：大约每 12–15 秒一次，用在每段话里最值得记住的那个词上。字体、颜色、入场方式要轮换，不能连续两次长得一样。
- 相邻两个事件不要用同一个视觉动词，也不要用同一种字体加同一种入场方式。
- 冲击帧（刀劈、门关上、重物落地）要和口播里那个字的发音时刻对齐（用 ASR 词级时间戳，误差 ≤2 帧），音效对齐同一帧。

## 5. 字体分工（文字也要有“表情”）

| 字体 | 情绪 | 用在 |
|---|---|---|
| 超粗黑体（Noto Sans SC Black） | 理性、有力 | 观点、数字、章节 |
| 粗宋体（Songti Black） | 情绪、分量、文学感 | 冲击字（割、关门）、引语、代价类重词 |
| 字语咏宋体等细宋 | 轻、文艺、温和 | 对比里较“轻”的一方、温和的总结 |
| 等宽字体 | 内心、系统、机器 | 独白、打字机、AI 输出 |

文字的表现手法要轮换使用，包括：逐字砸下、劈开、抖动、拉伸、描边空心、被挤小、手绘下划线、打字机、印章。

## 6. 自检（交付前逐条过）

1. **静音测试**：关掉声音、遮住字幕，只看画面，能说出这句在讲什么吗？
2. **指代测试**：画面里的对象是不是口播里被作用的那个东西？例如砍人要演人，不要演一根条。
3. **数量测试**：画面里的数量、比例是否和口播一致？
4. **节奏测试**：L4 次数是否 ≤8？任意 20 秒内是否最多一次 L4？人物后大字是否达到约每 12–15 秒一次？
5. **多样性测试**：相邻事件的视觉动词、字体、入场方式是否都不同？
