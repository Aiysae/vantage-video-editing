# 版式：16:9 与 9:16

两个版式共享同一套 tokens、组件和动作规则，差别只在**槽位位置、尺寸比例和多对象排列方向**。源片宽 ≥ 高用 16:9，否则用 9:16。

## 四种场景模式（两种画幅都有）

| mode | 画面 | 参考片占比 |
|---|---|---|
| `live` | 纯真人，不加图形（字幕除外） | 约 5% 事件 |
| `live+hud` | 真人＋角落 HUD 卡（导航、柱图、证据截图、胶囊标签） | 约 17% |
| `live+behind` | 真人＋人物后巨字/大数字/符号（遮罩遮挡） | 约 5%，但每次都是高光 |
| `graphic` | 全屏暗底＋品牌纹理＋多对象解释图形 | 约 73% 事件、65% 时长 |

## 16:9（1920×1080）

```
┌──────────────────────────────────────────────────────────┐
│ [A 左上 HUD]                              [B 右上 证据槽] │  A: x48 y48, 宽 ≈640 (34%)
│  章节导航/柱图/胶囊                        截图/照片/数据 │  B: 右48 上48, 宽 ≈640
│                                                          │
│        ████ 巨字区（人物头部高度带，y 120–420）████       │  live+behind
│                     ( 人物 )                              │
│                                                          │
│ ─ ─ ─ ─ ─ ─ ─ ─ 字幕安全区 y ≥ 930 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ │  HUD/图形不得进入
│              中文字幕 34px  /  English 20px               │
└──────────────────────────────────────────────────────────┘
```

- **graphic 构图**：横向 2–3 栏。常见组合：左对象（文稿/手机）＋右数据卡；左输入→中处理→右输出；中央主对象＋三角分布数据卡。主对象高度约画面 45–60%。
- **章节导航**：左上竖排 5 行（编号＋短名），当前项亮（text+cyan 点），其余 `text_faint`。真人段常驻，graphic 段隐藏或缩到左上角 60%。
- **人物偏左/偏右**：HUD 放在人物对侧上角；巨字从人物对侧起排，让遮挡发生在字的末端（参考：E129“多动脑”在左、“多练”在右，加号压在头后）。

## 9:16（1080×1920）

```
┌──────────────────────────┐
│ [顶部信息带 y 120–560]    │  HUD 横排：导航胶囊行 / 数据卡 / 证据卡
│  章节胶囊 · 数据 · 证据   │  宽 ≤ 42% 的卡可两张并排；或一张满宽 ≤ 968
│                          │
│  ██ 巨字区 y 300–700 ██   │  live+behind：巨字在头部上方并被头发/头顶遮挡
│        ( 人物 )          │
│                          │
│                          │
│ ─ 字幕安全区 y 1380–1620 ─│  人物胸口位置，参考抖音安全区；底部 300px 留给平台 UI
│   中文 48px / English 26 │
│ ─ 平台 UI 区 y ≥ 1620 ─ ─│  不放任何关键信息
└──────────────────────────┘
```

- **graphic 构图**：纵向 2–3 层。左右并排改为上下堆叠：上输入→中处理→下输出；数据卡放在主对象下方。主对象宽约画面 70–80%。
- **章节导航**：改为顶部横排胶囊（`01 选题 · 02 研究 · …`），只显示当前 ±1 项，避免挤压。
- **HUD 不得压脸**：脸部框（抽帧检测）扩 15% 作为禁区。
- **字号**：用 `type_scale_9x16`（比 16:9 大约 1.3×），因为手机竖屏观看时画面不再被缩小。

## 字幕安全区与 keep 模式

- `subtitle=bilingual`：本技能渲染字幕，所在区域即上面的字幕安全区。
- `subtitle=keep`：先抽帧标出原字幕实际所在矩形（含上下 12px 余量），作为**禁区**；所有 HUD、graphic 对象、巨字都不得进入。graphic 段若会盖住原片画面，原字幕也会被盖掉——此时需从原字幕文件/OCR 重新叠一层**同样式**字幕，或在 graphic 场景保留底部带显示原片对应区域。优先前者，并在报告说明。

## 尺寸自检

- HUD 卡宽：16:9 约 640px（字号上调后，2026-10-04），9:16 ≤ 560px（并排）或 ≤ 968px（单张满宽）。卡里放不下就删字或拆屏，不缩字号。
- 一屏可读文字层级 ≤ 4 级（标题 / 卡标题 / 正文 / 脚注）。
- graphic 段一屏 ≥ 2 个对象，或 1 个主对象＋数据/标签/来源脚注。只放一个居中图标视为不合格。
