# 字体与字幕

## 字体分工（用户已确认）

| 用途 | 字体 | 字重 | 说明 |
|---|---|---|---|
| 人物后巨字、大数字、章节标题、印章字 | 超粗黑体（display） | 900 | 参考片巨字就是超粗黑体。字重不够是旧样片“普通”的主因。 |
| 卡片标题、正文、标签、脚注、数据单位 | 无衬线 UI 体 | 400/500/700 | 宋体细笔画在小字号和暗底上会糊，不用于 UI。 |
| 数字（计数器、百分比、柱图数值） | 等宽数字（tabular-nums） | 700–900 | 计数滚动时宽度不跳动。 |
| 封面标题 | Songti-Black 宋体 | Black | 沿用用户认可的封面风格，见 delivery.md。 |
| 字幕 | 中文 UI 体 500；英文 UI 体 400 | | 见下。 |

### 情绪字体（2026-10-03 新增，见 semantics.md 第 5 节）

| 字体 | 情绪 | 用法 | 项目内 @font-face |
|---|---|---|---|
| 粗宋 Songti Black | 情绪、分量 | 冲击字（割、关门）、引语、代价类重词、人物后的情绪词 | `"KX Song"` → `fonts/SongtiBlack.ttf`（由项目提供字体文件） |
| 字语咏宋体 | 轻、文艺 | 较“轻”的对比项；keep 模式复刻剪映“口播-简约通用字幕” | `"ZY Song"` → 剪映缓存 `~/Movies/JianyingPro/User Data/Cache/effect/7312719367769166386/*/字语咏宋体.ttf` |
| 等宽 SF Mono / Menlo | 内心、机器 | 打字机独白、AI 输出 | 系统字体 |

人物后大字不能总用黑体：相邻两次换字体或换手法。

### 字体文件

渲染前把字体放进项目 `fonts/` 并用 `@font-face` 本地加载（渲染时不得走网络）。推荐（均可商用，需用户同意下载后放入 `components/fonts/`）：

- **Noto Sans SC**（SIL OFL）：Black 900 做 display，Regular/Medium/Bold 做 UI。首选，许可最干净。
- 备选：阿里巴巴普惠体 3.0 Black、HarmonyOS Sans SC Black（各自的免费商用许可，使用前确认许可文本）。

`components/fonts/` 已放入 Noto Sans SC Black / Bold / Medium / Regular（SIL OFL 1.1，来源 github.com/notofonts/noto-cjk，2026-10-03）。`scripts/new_project.sh` 会复制并生成 `fonts.css`。若在其他机器缺字体文件，回退系统字体并在报告中写明“巨字字重未达标”。

### 字号下限（用户 2026-10-04 反馈：左上小标题、章节导航太小看不清）

横屏 1920 宽的画面在手机上竖着看会缩到约 1/5，20px 只剩约 4pt。规则：**放出来就要看得清，看不清就不放。**

| 层级 | 16:9（1920×1080） | 9:16（1080×1920） |
|---|---|---|
| 一级（图形标题） | 72px | 72px |
| 二级（卡片标题、HUD 标题、清单标题） | 44px | 48px |
| 三级（章节导航、胶囊、清单项、正文） | 36px | 38px |
| 辅助（副标题、图表标签、来源、英文字幕） | 32px | 30px |
| **任何可读文字的下限** | **32px** | **30px** |

- 计算的是**最终渲染尺寸**：被缩小的元素（缩进角落的大字、缩小的卡片、录屏推近前的界面）按缩放后算。大字缩进 HUD 时，最终也要达到二级标题尺寸。
- 信息放不下时，**删字、拆成两屏或换成图标**，不要缩小字号。章节导航只显示当前项 ±1 项。
- 纯装饰的小字（背景纹理、英文角标、图标符号）加 `data-text-decor` 豁免检查，但它们不能承载必须读懂的信息。
- 交付前必须跑 `node scripts/text_size_audit.mjs <项目>/index.html`，有低于下限的可见文字就改。

### 巨字排版

- 字距 `-0.02em`～`0`；行高 1.0；不加描边，不加胶囊底。
- 白色巨字带轻微透明（`opacity .92`）和极淡投影（`0 8px 30px rgba(0,0,0,.35)`）；数字用 `yellow`。
- **背景亮度决定巨字颜色**：探测阶段算头部上方区域平均亮度；> 0.6（白墙、浅色背景）时在根节点加 `mu-light`，巨字改近黑色、HUD 加深。参考片是暗色布光，白字成立；用户素材常是白墙，直接套白字会几乎看不见（2026-10-02 实测）。
- 2–4 个字最有冲击力；超过 6 个字拆成两段先后出现（参考：多动脑 → ＋ → 多练）。

## 中英双语字幕（仅 `subtitle=bilingual`）

参考片样式：中文主行在上、英文副行在下，居中，**无底框、无描边**，靠极淡阴影保证可读。

| 项 | 16:9 | 9:16 |
|---|---|---|
| 中文 | 34px / 500 / `#ffffff` | 48px / 500 |
| 英文 | 20px / 400 / `rgba(255,255,255,.82)` | 26px / 400 |
| 行距（中→英） | 6px | 8px |
| 位置 | 中文基线 y≈1010 | 中文基线 y≈1480 |
| 阴影 | `0 1px 2px rgba(0,0,0,.6), 0 0 12px rgba(0,0,0,.35)` | 同 |
| 每屏 | 中文 ≤ 18 字一行，不换行；超长按语义断句拆屏 | 中文 ≤ 12 字一行 |

规则：
- 中文以口播为准逐句校对（术语、品牌名、人名），时间跟随实际发声，切点前后各留 ≥ 2 帧。
- 英文是**意译**而非逐字直译：简洁、口语、首字母大写、句末句号；专有名词保持原样（Agent、Skill、GEO）。每条英文 ≤ 60 字符，长句可省略口语填充。
- 中英同进同出，不做逐字动画；字幕层始终在最上层（L5），graphic 段也保留。
- 输出：`字幕-双语.srt`（中英两行同一条）＋ 烧录在成片中。导入剪映时用 SRT 生成字幕轨，样式按上表设置。

## `subtitle=keep`

源片已有字幕时：**不改字、不改时间、不加第二套**。只做避让（见 layout.md）。若需要在 graphic 段继续显示字幕，从原字幕文件/剪映字幕轨取文本，按原样式重叠，并在报告说明来源。
