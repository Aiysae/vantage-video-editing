# 真实素材：什么时候放、从哪来、怎么展示（用户 2026-10-04 确认）

参考：用户提供的优秀视频截图（`视频剪辑/ref-screens/`）。那条视频在讲教程/产品时，直接放真实录屏、界面截图、网页截图，用小窗或演示舞台呈现，旁边配步骤清单；作者说视频是用 Claude Code 做的。

## 1. 触发：哪些句子要放真实素材

在语义事件表里，凡满足任一条，就给这一场配真实素材（`mode: media`）：
- 讲**怎么用**某个工具 / 网站 / 软件（教程、操作步骤、“打开…点击…”）。
- 提到**具体页面或产品界面**（“仓库页”“飞书妙记的转写页面”“后台数据”）。
- 提到**可验证的事实来源**（官方公告、文档、规则页、榜单、数据）——放截图当证据。
- 抽象说法有现成场景能让人秒懂时（“你去 GitHub 拿到链接”→ 直接演一遍）。
没有真实来源时不伪造界面；只能做示意时标注“示意”。真实素材确实不存在的内容（抽象、比喻、设想、规模感），改用代码场景短片，见 `references/scenes.md`。

## 2. 来源：先查素材库，再自取，最后才问用户

| 顺序 | 来源 | 做法 |
|---|---|---|
| ① | 用户素材库 `./素材库/` | 按 项目素材目录 处理新投放，再运行 `scripts/asset_index.py --search "场景 主体 动作"`；检索内容描述、标签、用途、声音转写和片段时间，查看候选后复制到项目。原有文件名、目录名、同名 `.txt` 也保留检索。 |
| ② | Claude 自取（公开、可复现的） | **网页工具**：`scripts/record_web.mjs` 写动作脚本，无头浏览器真实操作，只录网页视口；同时记录光标轨迹和点击。**网页截图**：动作脚本里的 `shot`（可整页）。**桌面软件**：`scripts/record_app.sh` 只录目标窗口区域，由 Claude 用辅助功能/模拟点击操作。**品牌图标**：design/icons.md。 |
| ③ | 请用户提供（私有、要登录、要真实的） | 列一张“素材需求清单”：每条写清内容、用途（第几句）、格式（录屏/截图）、时长、需要打码的地方；用户统一放进桌面 `./素材投放/`，由 Agent 分析入库。 |

必须由用户提供或协助的情况：
- 需要登录**用户本人账号**的页面（抖音/视频号后台、飞书、付费工具）。Claude 不输入密码：用户先在浏览器里登录，再让 `record_web.mjs --user-data-dir=<该浏览器的资料目录>` 复用登录态；或者用户自己录好放进素材库。
- 真实数据、聊天记录、客户信息、线下照片和视频。
- 需要实名、付费或有风控（验证码）的操作。

## 3. 录屏规范（Agent 自己录）

- **只录工具本身**：网页用无头浏览器视口；桌面软件只录该窗口矩形，录前开勿扰、置顶窗口、关闭无关标签页。
- **按口播节奏写动作脚本**：先算这段口播有几秒，再安排滚动、点击、输入的时间（例：GitHub 样片 7 秒内完成浏览 → 点 Code → 复制链接）。首个页面在开录前加载好，不录白屏。
- **节奏**：鼠标移动 0.5–0.9 秒带缓动；点击后停 0.4–1 秒让结果出现；输入 12 字/秒左右。
- **隐私检查**：录完抽帧检查有没有账号名、邮箱、手机号、私人文件名；有就重录或打码。
- **记录来源**：每段素材在项目 `assets/SOURCES.md` 记一行（网址、录制时间、谁录的、用途）。
- 已知限制：无头浏览器录屏是 1280×800 原始分辨率，推近超过 2 倍会略软；桌面录屏会录到该区域内弹出的任何东西。

## 4. 展示（`components/media.js`）

| 形态 | 组件 | 何时用 |
|---|---|---|
| 素材小窗（PiP） | `MU.media.window` + `video`/`image` | 素材第一次出现：从相关图标/对象“弹出”，带标题栏（品牌图标＋网址）和来源角标“实录 · Claude 操作”；真人在角落时放画面中上部。 |
| 演示舞台 | 小窗放大 + `steps` + `stepsSync` + `cursor` + `autoZoom` | 讲操作步骤时：左上步骤清单与录屏同步打勾，放大光标＋点击波纹，跟随点击推近到按钮/结果，结束拉回全景。 |
| 证据截图卡 | `MU.media.window`（image）或 `MU.hudCard` + 截图 | 规则页、公告、数据表；配一个标题块（粗黑体主标题＋英文小字副标题）。长截图用 `autoZoom`/位移慢速滚动。 |
| 顶部章节进度条 | `MU.media.progress` | 长视频（>3 分钟）可选，横屏更合适；9:16 优先用 fusion-lib 的章节导航。 |

规则：
- 素材窗出现时，背景图形退到 5–10% 不透明度，焦点只有一个。
- 素材窗大小：9:16 宽 900–1000px；16:9 宽 1100–1400px（人物在一侧时放另一侧）。
- 光标和点击都来自真实录制的 `events.json`，不手动编造点击位置。
- 素材窗不压字幕安全区，不盖人物的脸。
